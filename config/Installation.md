# Installation

1. Stop your server.
2. Put `BetterFarming.jar` in your `plugins` folder.
3. Start your server.
4. Edit the generated files in `/plugins/BetterFarming`.
5. Restart your server after changing restart-only settings.

Always stop your server before installing updates. Config and locale files automatically add new entries, but they do not remove old custom entries.

# Optional Dependencies

BetterFarming can hook into these plugins if they are installed:

| Plugin type | Purpose |
| --- | --- |
| Vault economy | Money costs for farm purchases and upgrades. |
| Region or claim plugins | Placement checks and region-member access. Supported providers include Lands, SuperiorSkyblock2, BentoBox, PlotSquared, GriefPrevention, and WorldGuard. |
| UpgradeableHoppers | Automatic item output from farm storage into a hopper below the farm. |
| Hologram plugins | Farm status or fuel display through HolographicDisplays, CMI, or DecentHolograms. |

Continue with [Configuration](../admins/Configuration.md) after installing.
