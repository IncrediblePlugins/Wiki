# Installation

1. Stop your server.
2. Put the UpgradeableSpawners plugin jar in your `plugins` folder.
3. Start your server once.
4. Edit the configuration in `/plugins/UpgradeableSpawners`.
5. Restart the server.

Please always stop your server before installing updates. The config and locale files automatically
add new entries and remove entries that no longer exist.

# Optional Dependencies

UpgradeableSpawners can use these plugins when they are installed:

| Plugin type | Use |
| --- | --- |
| Vault economy | Money costs for spawner items, upgrades, entity types, and teleportation. |
| Lands, WorldGuard, BentoBox, SuperiorSkyblock2, or PlotSquared | Claim and region checks for placing, opening, and editing spawners. |
| CMI, DecentHolograms, FancyHolograms, or HolographicDisplays | Holograms above spawners. |
| UpgradeableHoppers | Collecting drops from butcher mode. |

After installing optional dependencies, restart the server so UpgradeableSpawners can hook into
them cleanly.
