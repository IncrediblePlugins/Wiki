# FasterFurnaces Player Wiki

This section explains FasterFurnaces from a player's point of view.

FasterFurnaces adds upgradeable furnaces, blast furnaces, and smokers. Depending on the server setup, upgrades can make items smelt faster, make fuel last longer, and change the amount of experience you receive.

Start with [Usage](Usage.md) if you are new to the plugin. Use [Commands](Commands.md) when you want the command reference.
