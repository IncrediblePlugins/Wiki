# What UpgradeableHoppers Does
UpgradeableHoppers lets you place special hoppers that can be improved over time. Instead of building long vanilla hopper lines, you can place one upgradeable hopper, link it to containers, and let it move items to those destinations.

Most values are configured by the server. This includes hopper types, prices, upgrade costs, maximum links, link distance, suction radius, and whether players can craft or buy hopper items.

# Main Features
Upgradeable hoppers can:
* Transfer multiple items per cycle.
* Pick up dropped items in a configurable suction radius.
* Send items to linked containers.
* Use filters for each linked container.
* Be upgraded through the hopper menu.
* Be viewed, opened, teleported to, or deleted from your hopper list.
