# Groups

Groups help you manage trusted players across many protections at once.

Instead of trusting the same players to every chest, barrel, door, or hopper manually, you can add
players to a group and assign protections to that group.

# Open Groups

Use `/chestprotect` and choose `Groups`.

From the groups menu you can create groups, edit existing groups, manage group players, and decide
which protection types should use the group automatically.

# Group Players

Players trusted to a group are automatically trusted to every protection in that group.

Use this for shared storage rooms, farms, doors, or other places where the same players need access
to several protections.

# Group Protection Types

A group can include protection types. If a newly created protection has one of those types, it can
be assigned to the group automatically.

Example:

1. Create a group named `Base`.
2. Add your trusted base members to the group.
3. Add `chest`, `barrel`, and `furnace` to the group's protection types.
4. New protections of those types can use the group without trusting each member manually.

# Default Group

The default group is used for protections that are not assigned to another group. It cannot be
deleted.

# Group Limits

Your server may limit how many groups you can create and how many players can be trusted to each
group.
