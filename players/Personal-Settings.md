# Personal Settings

Use `/chestprotect` and choose `Settings` to change your personal ChestProtect settings.

Your server may require permissions for some settings.

# Settings

| Setting | What it does |
| --- | --- |
| Auto Lock | Automatically locks protectable blocks when you place them, if you can pay the cost and have not reached your limit. |
| Persistent Lock, Unlock | Keeps lock and unlock mode active until you run `/chestprotect exit` or toggle the mode off. |
| Persistent Trust, Untrust | Keeps trust and untrust mode active until you run `/chestprotect exit` or toggle the mode off. |
| Notifications | Shows messages when you open one of your protections or a protection where you are trusted. |

# Auto Lock

Auto lock is useful when you want placed containers to be protected immediately.

Auto lock can fail if:

| Reason | What to do |
| --- | --- |
| You reached your protection limit. | Unlock unused protections or ask staff about limits. |
| You cannot pay the lock cost. | Get enough money or currency items. |
| The world or region does not allow protections. | Move to a location where you can lock objects. |
| The object type is not protectable. | Ask staff whether that object type is enabled. |

# Persistent Modes

Persistent modes are useful when you want to lock, unlock, trust, or untrust several protections in
a row.

If persistent mode is disabled, ChestProtect exits the mode after one successful action.

If persistent mode is enabled, remember to use `/chestprotect exit` when you are done.
