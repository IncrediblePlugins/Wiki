# Tickets

If the tickets module is enabled, you can open support tickets in Discord.

Tickets are private Discord channels for help requests, bug reports, questions, or other topics configured by the server.

# Open a Ticket

Most servers create a ticket panel in a Discord channel.

1. Open the server's ticket channel.
2. Choose a ticket type from the message menu.
3. Fill out the form.
4. Submit it.
5. DiscordBridge creates a private ticket channel for you and the support team.

There is usually no `/ticket create` slash command. Ticket creation normally starts from the ticket panel message.

# Use a Ticket Channel

In your ticket channel, explain the issue and answer staff questions.

The ticket summary shows the type, assigned support member, and the information you submitted. Staff may ask for more information, assign the ticket, close it, reopen it, or delete it depending on the server setup.

If your issue is solved, use the close button if the ticket message provides one.

# Add Another Member

If the server allows it, use this command inside the ticket channel:

```text
/ticket add member:<member>
```

This gives another Discord member access to the current ticket.

# Closed Tickets

Closed tickets may stay visible for a while or be deleted automatically after the server's configured deletion time.

If you still need help after a ticket was closed, use the reopen button if available or open a new ticket.
