Read [Start](Start.md) first if you are new to DiscordBridge.

# I do not see a command in Discord.

The matching module may be disabled, the bot may not have updated slash commands yet, or your Discord permissions may not allow the command.

Ask staff whether the feature is enabled.

# I was kicked because my account is not linked.

The server requires account linking before you can play.

Use the Discord command shown in the kick message. If the code expired, join again or run `/account link` in Minecraft to get a fresh code.

# Discord says my link code is invalid.

Codes are temporary and are valid for about 5 minutes.

Run `/account link` in Minecraft again, then immediately run `/account link code:<code>` in Discord with the new code.

# Discord chat is not reaching Minecraft.

Make sure you are typing in the server's configured chat channel.

If the bot tells you to link your account, link it first. If the bot does not respond at all, the feature may be disabled or the bot may be missing permissions.

# Minecraft chat is not appearing in Discord.

The server may have Minecraft-to-Discord chat disabled, the Discord channel may not be configured, or another chat plugin may be cancelling the message before DiscordBridge can send it.

Ask staff to check the chat module.

# I linked my account but did not receive rewards, roles, or groups.

Those features are optional. The server owner decides whether linking gives rewards, Discord roles, or in-game groups.

Some updates can also take a short while on large servers.

# I cannot create a Lands channel.

You need a linked account, and your linked Minecraft account must own the land or nation unless you have Discord administrator permission.

The server also needs to have Lands channel creation enabled.

# I cannot open a ticket.

Tickets may be disabled, the ticket panel may not be configured, or you may already have the maximum number of active tickets allowed by the server.
