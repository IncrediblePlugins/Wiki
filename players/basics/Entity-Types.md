# Entity Types

Each upgradeable spawner has a selected entity type. This is the entity it tries to spawn.

# Change the Entity Type

1. Right-click the spawner to open its menu.
2. Click the entity type item.
3. Select the entity type you want.

If the entity type was not purchased for this spawner yet, the server may charge money before it is
unlocked.

# Entity Permissions

Servers can lock entity types behind permissions. The permission format is:

`uspawners.mob.<mob>`

Replace `<mob>` with the entity name used by your server. The entity menu shows whether an entity
type is unlocked for you.

# Purchased Entity Types

Purchased entity types are saved on that spawner. After you buy one for a spawner, you can switch
that spawner back to it without buying it again.

Breaking and replacing the spawner keeps its purchased entity types.

# Spawn Eggs

Some servers allow changing a spawner's entity type with spawn eggs. Other servers disable egg
changes and require you to use the spawner menu instead.
