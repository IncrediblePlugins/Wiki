# Commands

These are the player commands for FasterFurnaces. The help command only shows commands that you have permission to use.

| Command | Description | Permission |
| --- | --- | --- |
| `/fasterfurnaces` | Opens the command menu. This has the same effect as `/fasterfurnaces help`. | `fasterfurnaces.command.menu` |
| `/fasterfurnaces help [page]` | Shows command usage information. | `fasterfurnaces.command.help` |
| `/fasterfurnaces get [type] [amount]` | Gives you upgradeable furnace items. If no type is entered, the server's default type is used. | `fasterfurnaces.command.get` |
| `/fasterfurnaces list` | Opens a list of your placed furnaces. | `fasterfurnaces.command.list` |
| `/fasterfurnaces confirmtp` | Confirms a teleport destination that may be unsafe. | None |

Examples:

* `/fasterfurnaces get`
* `/fasterfurnaces get furnace 1`
* `/fasterfurnaces get blast_furnace 2`

Your server may configure different furnace type names, prices, permissions, or command aliases.
