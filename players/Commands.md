# Commands

The examples on this page use `/spawners`. Depending on your server configuration, the same
commands may also be available through aliases such as `/spawner`, `/uspawners`, or
`/upgradeablespawners`.

Some servers charge money for spawner items, upgrades, entity types, or teleportation. Some
servers also limit commands by permission, world, claim, or rank.

| Command | What it does | Permission |
| --- | --- | --- |
| `/spawners get [amount]` | Gets one or more upgradeable spawner items. If the server charges for spawner items, you may need to confirm the purchase. | `uspawners.command.get` |
| `/spawners list` | Opens a menu with your placed spawners. From there you can open a spawner menu or teleport to a spawner if teleportation is enabled. | `uspawners.command.list` |
| `/spawners confirmtp` | Confirms an unsafe teleport destination after using spawner teleportation. | `uspawners.command.confirmtp` |
