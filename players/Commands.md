The following aliases for the `/upgradeablehoppers` command exist by default:
* `/uhoppers`
* `/uhopper`
* `/hoppers`
* `/hopper`
* `/uh`
* `/h`

# Player Commands

`/upgradeablehoppers get [type] [amount]`\
Get or purchase hopper items. If you want to buy more than one hopper, provide the hopper type before the amount.\
*Permission: uhoppers.command.get*

`/upgradeablehoppers list`\
Open a menu with your placed hoppers. From this menu you can open, teleport to, or delete hoppers.\
*Permission: uhoppers.command.list*

`/upgradeablehoppers view`\
Visualize nearby hoppers and links. Execute the command again to disable the visualization.\
*Permission: uhoppers.command.view*

`/upgradeablehoppers abort`\
Abort the current link or unlink mode.\
*Permission: uhoppers.command.abort*

`/upgradeablehoppers confirmtp`\
Confirm an unsafe teleport destination. This is used after the plugin warns you that a hopper teleport target is not safe.\
*Permission: uhoppers.command.confirmtp*

`/upgradeablehoppers help`\
List available commands.\
*Permission: uhoppers.command.help*
