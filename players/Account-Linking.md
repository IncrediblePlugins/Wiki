# Account Linking

Account linking connects one Minecraft account with one Discord account.

Servers can use linking for Discord roles, in-game groups, name sync, one-time rewards, Discord-to-Minecraft chat, Lands channels, or join requirements.

# Link Your Account

1. Join the Minecraft server.
2. Run `/account` or `/discordbridge account`.
3. Click the link option, or run `/account link`.
4. Copy the code shown in Minecraft.
5. In the Discord server, run `/account link code:<code>`.

The code is valid for about 5 minutes. If Discord says the code is invalid, run the Minecraft command again and use the new code.

# If Linking Is Required to Play

Some servers require linked accounts. If you are kicked because your account is not linked, the kick message shows the Discord command and may include the Discord invite.

Join the Discord server, run the shown `/account link code:<code>` command, and then join Minecraft again.

# Unlink Your Account

You can unlink from either side:

| Where | Command |
| --- | --- |
| Minecraft | `/account unlink` or `/discordbridge account unlink` |
| Discord | `/account unlink` |

You can also open `/account` in Minecraft and click the linked account item, if your server uses the account menu.

If the server requires linked accounts, unlinking may stop you from joining until you link again.

# Roles, Groups, Names, and Rewards

Server owners decide what linking changes.

Depending on the server setup, linking may:

| Result | What it means |
| --- | --- |
| Discord roles | You receive configured Discord roles after linking. |
| In-game groups | You receive configured permission groups in Minecraft. |
| Name sync | Your Discord nickname may be updated to your Minecraft name. |
| Rewards | You may receive one-time in-game rewards. |

Some updates can take a short while. Name sync can take longer on large servers.

# Common Problems

| Problem | What to try |
| --- | --- |
| The code is invalid. | Run `/account link` in Minecraft again and use the new code. |
| Discord says you are already linked. | Use `/account unlink` in Discord first, then link again. |
| Minecraft says you are already linked. | Use `/account unlink` in Minecraft first, then link again. |
| Discord says only certain roles can link. | Ask staff which Discord role is required. |
| You did not receive a role, group, or reward. | Ask staff whether that feature is enabled on the server. |
