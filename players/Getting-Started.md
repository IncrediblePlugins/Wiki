This page explains how you get started with your first upgradeable hopper.

# Get a Hopper
Depending on the server, you can receive hopper items by command, crafting recipe, shop, or an admin.

Command: `/upgradeablehoppers get [type] [amount]`\
If the server has multiple hopper types, provide the type name. If you want more than one hopper, provide the type before the amount.

Examples:
* `/uhoppers get`
* `/uhoppers get normal 3`
* `/uhoppers get chunk 1`

The default command aliases usually include `/uhoppers`, `/uhopper`, `/hoppers`, `/hopper`, `/uh`, and `/h`. Server owners can change aliases.

# Place a Hopper
Place the hopper item like a normal hopper. The hopper becomes yours after placement.

Some servers may restrict where you can place upgradeable hoppers. For example, placement might only be allowed in specific worlds or inside claims where you are trusted.

# Open the Hopper
Left-click an upgradeable hopper without sneaking to open its upgrade menu.

Right-click an upgradeable hopper to open its inventory.

Sneak while breaking the hopper if you want to remove it. If protection is enabled, only the owner, trusted players, or staff can remove it.

# Basic Setup
1. Place the upgradeable hopper.
2. Open the hopper menu by left-clicking it without sneaking.
3. Use `Link to Containers` and click a destination container.
4. Put items into the hopper or let it pick up dropped items.
5. Upgrade the hopper as needed.

# Hopper Types
Servers can configure their own hopper types. By default, UpgradeableHoppers includes a normal hopper and a chunk hopper.

Normal hoppers use a block-based suction radius.

Chunk hoppers can use a chunk-based suction radius, depending on the server configuration.
