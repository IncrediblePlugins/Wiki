# BetterFarming Admin Guide

This section is for server owners and staff who install, configure, and moderate BetterFarming.

BetterFarming is driven by configuration. Farms, harvestable blocks, fuel, upgrades, limits, roles, storage, placement rules, and integrations can all be adjusted for your server.
