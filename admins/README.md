# FasterFurnaces Admin Wiki

This section is for Minecraft server owners and staff who configure FasterFurnaces.

FasterFurnaces is built around configurable upgradeable furnace types. Most server setup happens in `config.yml`, `furnaces.yml`, `player-limits.yml`, `roles.yml`, and the GUI/message files.
