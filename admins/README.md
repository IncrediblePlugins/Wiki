Here you can find information on how to install, configure, and manage UpgradeableHoppers as a server admin.

# What Admins Configure
The plugin is split into two main configuration files:
* `config.yml` controls worlds, database, command aliases, vanilla hopper restrictions, protection, integrations, teleportation, economy, optimization, and default settings.
* `hoppers.yml` controls hopper types, prices, recipes, transfer and suction intervals, linkable containers, particles, type permissions, and upgrade levels.

Most day-to-day changes are made in `config.yml`. Changes to `hoppers.yml` require a full server restart.
